
# Kaveri — Women's Fashion E-commerce

Kaveri is a women's fashion e-commerce application designed to
provide an elegant shopping experience and a centralized
administration interface for managing the store.

## Features

- Browse women's fashion products
- Explore product categories and designers
- Add products to a wishlist
- Manage shopping cart items
- Administrative dashboard for store management
- Product, category, order, and customer management
